# Overlay ZIP Kit privacy policy

Overlay ZIP Kit opens user-selected widget ZIPs or code files and fills the Custom Widget editor in the current StreamElements overlay. It reads the code of a selected widget when the user requests an export and creates a ZIP download in Chrome.

The extension processes files and widget code in browser memory. It has no backend, analytics, tracking, or extension storage. It does not collect account credentials or send the developer your files, widget code, browsing history, or account information.

Importing places your code in the StreamElements editor. When you save the overlay, StreamElements handles the widget and its settings under its own policies. Code within a widget can make its own requests when StreamElements runs that widget. The extension itself does not execute code from the archives it opens.

The extension only runs on matching StreamElements overlay editor pages. It uses the code editor provided on that page to access the five Custom Widget tabs. The extension does not sell or share user data with a separate service. Its handling of user data follows the Chrome Web Store User Data Policy, including the Limited Use requirements.

For privacy questions, contact the maintainer through the [public project page](https://github.com/kalderbabasina/overlay-zip-kit). Please omit private widget files or account details from public reports.
